# IRAN RADAR — خبرخوان اولیه

این نسخه یک **MVP برای گردآوری و صف بررسی خبر** است؛ هنوز سامانه را بدون آزمایش نباید در حالت انتشار بی‌نظارت گذاشت.

## جریان کار

1. GitHub Actions هر ۱۰ دقیقه اجرا می‌شود.
2. `news_collector.py` خوراک‌های RSS و پیش‌نمایش عمومی کانال `@wfwitness` را می‌خواند.
3. فقط مواردی که کلیدواژه‌های مرتبط با ایران دارند به Apps Script فرستاده می‌شوند.
4. Apps Script موارد تکراری را حذف می‌کند، ترجمه ماشینی فارسی می‌سازد و در برگه `NewsQueue` ذخیره می‌کند.
5. ویراستار در ستون L وضعیت را به `تأیید` تغییر می‌دهد. ستون M برای متن نهایی ویراستاری‌شده است.
6. تابع زمان‌بندی‌شده `publishApprovedNews` موارد تأییدشده را به `@RadarIranNews` می‌فرستد.

## راه‌اندازی

### ۱) Google Sheets و Apps Script

- یک Google Sheet تازه بساز.
- از Extensions → Apps Script وارد محیط اسکریپت شو و محتوای `apps_script/Code.gs` را جایگزین کن.
- در Project Settings → Script Properties این دو مقدار را بساز:
  - `GITHUB_WEBHOOK_SECRET`: یک رشته تصادفی طولانی و محرمانه.
  - `TELEGRAM_BOT_TOKEN`: توکن ربات اختصاصی IRAN RADAR.
- ربات باید در کانال `@RadarIranNews` ادمین و مجاز به ارسال پیام باشد.
- Deploy → New deployment → Web app؛ اجرا با حساب خودت و دسترسی Anyone. نشانی `/exec` را نگه دار.
- در Apps Script تابع `getOrCreateSheet_` را از ویرایشگر اجرا کن تا برگه ساخته شود؛ مجوزها را تأیید کن.
- بعد از استقرار، تابع `installPublishTrigger` را یک بار اجرا کن.

### ۲) GitHub

- محتویات این پوشه را در یک مخزن خصوصی جدید قرار بده.
- در Settings → Secrets and variables → Actions این Secrets را بساز:
  - `APPS_SCRIPT_URL`: نشانی Web App با انتهای `/exec`.
  - `APPS_SCRIPT_SECRET`: دقیقاً همان مقدار `GITHUB_WEBHOOK_SECRET`.
- از Actions اجرای دستی `Iran Radar News Collector` را بزن.

## ستون‌های صف خبر

- ستون L: `در انتظار بررسی`، `تأیید`، `رد` یا `منتشر شد`.
- ستون M: اگر متن ویرایش‌شده در آن باشد، همان متن منتشر می‌شود؛ در غیر این صورت ترجمه ماشینی استفاده می‌شود.

## محدودیت‌های مهم نسخه اول

- تشخیص ارتباط با ایران مبتنی بر کلیدواژه است و ممکن است خبر مرتبطی را از دست بدهد یا مورد نامرتبطی را وارد صف کند.
- ترجمه Google Apps Script ماشینی است؛ نقل‌قول‌ها، اعداد، مکان‌ها و ادعاهای حساس باید پیش از انتشار با منبع اصلی تطبیق داده شوند.
- جمع‌آوری از `t.me/s/` به دسترسی عمومی صفحه وابسته است و ممکن است با تغییر ساختار تلگرام از کار بیفتد.
- خوراک‌های RSS ممکن است محدود یا تغییر کنند؛ اجرای Actions تضمین تحویل دقیقاً هر ۱۰ دقیقه نیست.
- در این نسخه تصویر/ویدئو بازنشر نمی‌شود؛ فقط لینک منبع در پیام قرار می‌گیرد تا حقوق رسانه و صحت مدرک حفظ شود.
- خبرها مستقیماً و بدون تأیید انسانی منتشر نمی‌شوند.

## آزمون امن

ابتدا یک خبر آزمایشی در صف بررسی ببین؛ سپس در ستون L آن را رد کن. فقط پس از اطمینان از اینکه هیچ پیام ناخواسته‌ای منتشر نمی‌شود، یک خبر کم‌خطر را با متن ویرایش‌شده تأیید کن.
