## قابلیت‌های جدید (کیفیت و اعتماد)

- **برچسب گزارش اولیه:** خبرهای نظامی زنده با «⚠️ گزارش اولیه؛ هنوز از منبع دوم تأیید نشده» منتشر می‌شوند و وقتی کانال *دیگری* همان رویداد را گزارش کند، همان پیام ویرایش می‌شود به «✅ تأیید شده توسط چند منبع». (اظهارات مقام‌ها و اقتصاد برچسب نمی‌گیرند.) خاموش: `SINGLE_SOURCE_LABEL=0`. توجه: دو کانال که یک خبر خبرگزاری را بازنشر کرده‌اند مستقل شمرده می‌شوند.
- **dedup رویدادمحور:** همان شهر + همان نوع رویداد (انفجار/پدافند/حمله/موشک/پهپاد…) در ۴۵ دقیقه = یک رویداد، حتی اگر فارسی و انگلیسی باشند یا AI جمله را متفاوت نوشته باشد (`EVENT_DEDUP_MINUTES`، صفر = خاموش).
- **اعلان بی‌صدا:** خبر عادی بدون اعلان گوشی؛ فقط breaking یا `impact=high` صدا دارد (`SILENT_NON_URGENT=0` برای خاموش‌کردن).
- **ضد prompt-injection:** متن منبع بین `<source_post>` قرار می‌گیرد و پرامپت صریحاً آن را «داده» می‌داند.
- **لاگ خبرهای منتشرنشده:** دلیل هر skip (`ai_skip`، `too_short`، `gave_up`، `send_unknown`) در state نگه داشته می‌شود؛ در GitHub Actions جدولش در *Job summary* می‌آید؛ محلی: `python main.py --show-skips`.

## متغیرهای محیطی جدید (همه اختیاری)
`ITEM_BUDGET_SECONDS` (۶۰)، `EVENT_DEDUP_MINUTES` (۴۵)، `URGENT_ANY_STATEMENT` (۰)، `SINGLE_SOURCE_LABEL` (۱)، `SILENT_NON_URGENT` (۱)، `AMBIGUOUS_SEND_POLICY` (`skip` یا `retry`)، `OPENROUTER_REFERER`.
متغیرهای قبلی (`ADMIN_CHAT_ID`، `GROQ_MODELS`، `MAX_PER_CYCLE` …) بدون تغییرند.

## تست
```
pip install -r requirements.txt
python -m unittest discover -s tests -v      # ۶۳ تست آفلاین، بدون شبکه
DRY_RUN=1 python main.py --once              # خروجی را چاپ می‌کند و چیزی نمی‌فرستد
python main.py --show-skips                  # آخرین خبرهای منتشرنشده و دلیلشان
```

## نکته‌ها
- فرمت state سازگار با نسخهٔ قبل است (فیلدهای جدید خودکار ساخته می‌شوند)؛ cache فعلی گیت‌هاب معتبر می‌ماند.
- ریسک‌های قبلی هنوز برقرارند: ریپوی public بدون commit بعد از ۶۰ روز workflow زمان‌بندی‌شده را غیرفعال می‌کند؛ اجرای ۲۴ ساعته روی ریپوی private سهمیهٔ رایگان Actions را می‌سوزاند (برای تأخیر کم‌تر VPS/Fly بهتر است).
- AI فقط روی ورودی «بازنویسی» می‌کند؛ برای خبر جنگی همچنان بازبینی انسانی/لاگ skip را دوره‌ای نگاه کنید.
