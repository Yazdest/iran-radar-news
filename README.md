# Radar News — کانال خبری تلگرام

خبر از رسانه‌های معروف جهان (BBC، الجزیره، فرانس۲۴، DW، گاردین، NYT، اسکای‌نیوز، CNN، رویترز، AP) و کانال‌های تلگرامی منبع
را می‌گیرد، با ترجمه روان فارسی و **بدون صف تأیید** در کانال منتشر می‌کند.

## شکل پیام‌ها
- خبر مهم و تازه: `🚨 #خبر_فوری` + عنوان + متن
- خبر روایی/شاهدمحور: `🎙 #روایت` + عنوان + متن در قالب نقل‌قول
- خبر معمولی: `📰` + عنوان + متن
- پایین پیام: `📡 به گزارش رویترز` (یا برای کانال تلگرامی: `📡 منبع: wfwitness` بدون @ و بدون لینک)
- عکس/ویدیو: دانلود و به‌صورت **فایل مستقل** آپلود می‌شود (نه لینک، نه فوروارد). عکس مرجع RSS از `og:image` صفحه خبر گرفته می‌شود.

## راه‌اندازی
1. فایل‌ها را در ریشه مخزن بگذار (فایل workflow باید در `.github/workflows/news.yml` باشد).
2. ربات را ادمین کانال کن (دسترسی ارسال پیام).
3. Secrets (Settings → Secrets and variables → Actions):
   - `TELEGRAM_BOT_TOKEN`
   - `ANTHROPIC_API_KEY` (برای ترجمه روان؛ بدون آن ترجمه ماشینی ساده استفاده می‌شود)
4. از Actions دستی `Radar News` را اجرا کن.

> اولین اجرا فقط خبرهای موجود را «دیده‌شده» ثبت می‌کند و چیزی منتشر نمی‌کند؛ از اجرای بعد خبرهای تازه می‌آیند.
> برای تست فوری: `BOOTSTRAP=0`.

## سرعت
- GitHub Actions با cron دقیق نیست. این نسخه هر ۱۵ دقیقه یک job می‌سازد که ۱۷ دقیقه **هر ۳۰ ثانیه** منابع را چک می‌کند (تأخیر معمول: زیر ۱ دقیقه).
- این روش در مخزن **عمومی** رایگان است. در مخزن خصوصی سهمیه ۲۰۰۰ دقیقه‌ای ماه در حدود ۱.۵ روز تمام می‌شود.
- بهترین حالت: یک سرور/VPS کوچک و `python main.py` (برای همیشه اجرا می‌شود) با متغیرهای محیطی همان Secrets.

## اجرا روی سرور / تست
```bash
pip install -r requirements.txt
export TELEGRAM_BOT_TOKEN=... ANTHROPIC_API_KEY=...
python main.py                     # دائمی
DRY_RUN=1 BOOTSTRAP=0 python main.py --once   # فقط چاپ پیام‌ها، بدون ارسال
```

## تنظیمات (`config.py` یا متغیر محیطی)
| نام | پیش‌فرض | توضیح |
|---|---|---|
| `TELEGRAM_CHANNEL` | `@RadarIranNews` | کانال مقصد |
| `POLL_SECONDS` | 30 | فاصله چک منابع |
| `MAX_AGE_MINUTES` | 180 | خبر قدیمی‌تر منتشر نمی‌شود |
| `SHOW_ARTICLE_LINK` | 0 | `1` = لینک خبر اصلی RSS هم بیاید |
| `ANTHROPIC_MODEL` | `claude-haiku-5-5` | مدل ترجمه |

منابع RSS و کانال‌های تلگرامی (`TELEGRAM_SOURCES`) و فیلتر ایران (`filter_iran`) در `config.py` هستند.
برای انتشار همه خبرهای یک کانال تلگرامی `"filter_iran": False` بگذار.
