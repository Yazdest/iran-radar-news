# Radar News — کانال خبری تلگرام

فقط خبرهای مرتبط با **ایران**: اظهارات ترامپ و کابینه، نتانیاهو و دولت اسرائیل، مقامات ایران، تحولات مهم نظامی/هسته‌ای/دیپلماتیک،
و ارزیابی رادیو و تلویزیون اسرائیل. بقیه اخبار (غزه، لبنان، حاشیه‌ها و ...) منتشر نمی‌شود.

## شکل پیام
```
🚨 #خبر_فوری · عنوان کامل و مفهوم      ← خبر فوری
🚀 عنوان کامل و مفهوم                  ← بقیه اخبار: فقط ایموجی مناسب موضوع (بدون برچسب)
متن حداکثر ۱ تا ۲ جمله  (خبر تأثیرگذار: تا ۴ جمله)
📡 رویترز · 📢 @RadarIranNews
```
هر خبر ابتدا با کارت مربعی ۱:۱ و پس‌زمینه روشن منتشر می‌شود؛ در صورت وجود، تصویر اصلی خبر نیز به‌عنوان تصویر تکمیلی در همان آلبوم می‌آید. در خبرهای مبتنی بر اظهارات ترامپ، روبیو، نتانیاهو و قالیباف، پرتره گوینده از Wikimedia Commons دریافت و در کارت با نوار نام گوینده قرار می‌گیرد. کارت توییت مقامات نیز مربعی است و رسانه خود توییت پس از آن قرار می‌گیرد.
عکس/ویدیوی کانال‌های تلگرامی به‌صورت فایل مستقل و بدون لینک آپلود می‌شود؛ منبع تلگرامی فقط یک کلمه ساده است.

## حذف تبلیغات
دو لایه: (۱) فیلتر خودکار در `sources.py` که خط‌ها و جمله‌های «عضو شوید/فالو کنید/کانال ما»، لینک و @، امضا و هشتگ‌های پایین پست و فوتر بعد از خط جداکننده را پاک می‌کند و پست‌های کاملاً تبلیغاتی (sponsored، کد تخفیف و ...) را کنار می‌گذارد؛ (۲) دستور ویرایشگر هوش مصنوعی که بقیه تبلیغات و برند خود منبع را حذف می‌کند و اگر خبر واقعی باقی نماند آن را رد می‌کند.
اگر کانالی عبارت تبلیغاتی خاصی دارد، الگوی آن را در `strip_lines` همان کانال در `config.py` اضافه کن.

## منابع
BBC، الجزیره، تایمز اسرائیل، رویترز/AP/بلومبرگ/Axios (از Google News)، جست‌وجوهای مستقل Google News برای جنگ، حملات، موشک و پرونده هسته‌ای، رادیو و تلویزیون اسرائیل (کان، شبکه ۱۲، ۱۳، i24، وای‌نت)،
رسانه‌های ایرانی (پرس‌تی‌وی، تسنیم، مهر، ایرنا، فارس)، پست‌های ترامپ، توییت مقامات (`TWEET_ACCOUNTS` در `config.py`)، و کانال تلگرامی `wfwitness`.

## راه‌اندازی
1. فایل‌ها را در مخزن بگذار؛ workflow باید در `.github/workflows/news.yml` باشد.
2. Secrets: `TELEGRAM_BOT_TOKEN` و یکی از `GEMINI_API_KEY` (رایگان) یا `ANTHROPIC_API_KEY`.
   **کلید هوش مصنوعی الزامی است.** بدون آن ربات اجرا نمی‌شود (خطا می‌دهد)، چون ترجمه ساده گوگل متن‌های ناقص و بی‌معنی می‌سازد.
   اگر ترجمه موقتاً در دسترس نباشد، خبر منتشر نمی‌شود؛ در صف باقی می‌ماند و با فاصله افزایشی دوباره امتحان می‌شود تا زمانی که از پنجره عمر خبر خارج شود. برای قبول ترجمه ضعیف: `ALLOW_FALLBACK=1`.
3. فونت فارسی: workflow خودش Vazirmatn را دانلود می‌کند. مطمئن‌تر: دو فایل `Vazirmatn-Bold.ttf` و `Vazirmatn-Regular.ttf` را در پوشه `fonts/` مخزن بگذار.
4. Actions ← Run workflow. در اولین اجرا، خبرهای حداکثر ۶ ساعت اخیر به‌تدریج منتشر می‌شوند؛ برای رد کردن خبرهای موجود و شروع فقط از خبرهای جدید، `BOOTSTRAP=1` تنظیم کن.
5. فونت‌های ارسالی در `fonts/` ساماندهی شده‌اند: `B-Titr-Bold.ttf` برای تیتر و `B-NAZANIN.ttf` برای متن‌های کمکی. هر دو باید در مخزن باقی بمانند.

## اجرا روی سرور / تست
```bash
pip install -r requirements.txt
export TELEGRAM_BOT_TOKEN=... GEMINI_API_KEY=...
python main.py                                  # دائمی
DRY_RUN=1 BOOTSTRAP=0 python main.py --once     # فقط چاپ پیام‌ها
```

## تنظیمات مهم (`config.py`)
`RSS_FEEDS`، `TELEGRAM_SOURCES`، `TWEET_ACCOUNTS`، `NITTER_INSTANCES`، `CHANNEL_SIGNATURE`، `SHOW_ARTICLE_LINK`، `MAX_PER_CYCLE`، `POLL_SECONDS`.

## پایداری منابع X
دریافت پست‌های X همچنان به RSS عمومی Nitter وابسته است و این سرویس‌ها ممکن است موقتاً از دسترس خارج شوند. خطای یک حساب دیگر باعث توقف تلاش برای حساب‌های دیگر نمی‌شود؛ با این حال اگر همه نمونه‌های Nitter از کار افتاده باشند، دریافت مستقیم X تضمین‌شده نیست. خبرهای اصلی جنگ از جست‌وجوهای مستقل Google News و RSS خبرگزاری‌ها نیز دریافت می‌شوند؛ بنابراین انتشار خبر فقط به Nitter وابسته نیست.

## محدودیت زمان‌بندی GitHub
GitHub Actions در این تنظیم هر ۵ دقیقه اجرا می‌شود و در هر اجرا ۴ دقیقه منابع را بررسی می‌کند. زمان‌بندی GitHub تضمین لحظه‌ای ندارد و ممکن است در ساعات شلوغ با تأخیر انجام شود؛ برای انتشار نزدیک به لحظه (مثلاً هر ۳۰ ثانیه) اجرای دائمی روی VPS لازم است.

## اعتبار تصاویر اشخاص
پرتره‌ها از Wikimedia Commons انتخاب شده‌اند. تصویر ترامپ و روبیو در مالکیت عمومی دولت آمریکا است؛ تصویر نتانیاهو با مجوز CC BY-SA 3.0 و تصویر قالیباف با CC BY 4.0 منتشر شده‌اند. اعتباردهی هر تصویر در کد و نوار پایین کارت درج می‌شود.

### پوسترهای تصویری خبر
پوسترهای خبری در صورت وجود، از تصویر همراه RSS/تلگرام یا تصویر اصلی صفحه خبر استفاده می‌کنند. اگر تصویر در دسترس نباشد، سیستم تلاش می‌کند تصویر مرتبط موضوع را از Wikimedia Commons پیدا کند؛ اگر تصویر قابل‌اتکا پیدا نشود، پوستر گرافیکی بدون عکس منتشر می‌شود. تصویر چهره مقام‌ها فقط برای خبرهای منتسب به همان فرد و به‌عنوان جایگزین آخر استفاده می‌شود.
